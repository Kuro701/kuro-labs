Vretil

Files and scheduling in plain language: find it, read it, write it, file it, remind me about it.

Python / Flask / Durable scheduling / Intent gate

View repository ↗

Vretil is the sub-mind that does the boring things: finding a file, writing one, putting it somewhere sensible, and remembering to mention it on Thursday. It runs through the conversational model that is already loaded rather than bringing its own, which on a single-GPU machine is the difference between a feature and a model swap.

Flat beats tidy

New files are classified against a registry of existing categories, and anything genuinely new gets a folder at the top level — never nested. Deep hierarchies look organised for about a month and then nobody can find anything. Flat and searchable survives contact with actual use.

The gate is what makes it free

A lightweight intent check runs before anything reaches a model, so a normal conversation never pays for the filesystem feature. Only a request that actually looks like one goes further — and when it does, new content is resolved against what already exists, appending to a log or overwriting a correction as the case warrants, rather than dropping a near-duplicate beside it.

Two one-line bugs worth the mention

Both surfaced only on real hardware and both were a single line. The panel was missing from the clickable list during an orb collapse, so it stopped taking clicks at exactly the wrong moment; and the resize handles sat outside the registered click-through region, so they looked draggable and were not. Neither shows up in code review. They show up when somebody actually clicks the thing. Write-up on GitHub.
