Mytheder

A Czech party card game, rebuilt from an abandoned repo and given a new identity for a Discord community.

Svelte / TypeScript / WebSocket / Cloudflare / Render

View repository ↗Open Mytheder ↗

The original author shut the project down and released the code. I rebuilt it: deleted the database, removed the dead accounts system, wrote the chat that was never finished, and re-skinned it for a Discord server that wanted its own version. It now runs as part of this site rather than on somebody's spare subdomain.

The database was doing nothing

The game only ever read cards from MySQL — three queries, no writes. All 1016 cards now load from JSON at boot and the entire database layer is gone. Adding cards is editing a file; there are no migrations.

Most of the work was failure handling

The bugs that actually ruined games were never about rules.

  • A one-second auth timeout was fine on localhost and killed every real connection through a proxy
  • One dropped socket ended everyone's game, because rooms were destroyed the moment they fell below three players
  • A small pack could run its prompt pile dry and take the room down with it
  • A player who dropped out of a full game was locked out by a headcount they were still part of

Re-skinnable by design

The first build hard-coded one accent colour across ten components. Every colour now resolves from three tokens, so giving a new community its own version is a config change and four images rather than a hunt through the codebase.
