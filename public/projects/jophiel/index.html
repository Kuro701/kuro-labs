Jophiel

Local image generation and editing, on the same 12GB card everything else is already fighting over.

Python / ComfyUI / FLUX.1 [schnell] / Qwen-Image-Edit / CUDA

View repository ↗

Jophiel is the fourth sub-mind and the second heavy engine, which is what made it the awkward one to add: the card was already spoken for. Generation and editing are one skill in two modes — Quill makes a picture, Eye changes one — and an image can be thrown from either to the other.

Two modes, told apart by how they move

Both modes share a layout — showcase image, filmstrip history, prompt bar — so the only thing separating them could have been a word in the header. Instead they have different visual languages: soft ink-bloom motion for generation, a slowly rotating iris and scan-line for editing. You know which mode you are in before you have read anything.

The engine that would not die

The first build stopped the wrapper process and reported the engine off. It was not off — the real engine was still resident and still holding VRAM, which on a shared 12GB card is the whole problem wearing a disguise. The fix was Metatron's: kill the process tree, not the parent. Verified by actually restarting and watching the memory come back, because the bug's entire nature was reporting success while failing. Write-up on GitHub.
