Software and AI, specifically

This is the part I get asked about least and have built most. Cloe is a local AI companion with a persistent graph memory and a transparent desktop presence; Metatron is an image-to-3D pipeline that schedules its own VRAM so one consumer card can host a generation engine and a language model without either falling over. Both run entirely on one machine.

Local AI

Assistants that stay yours

An assistant running on your own hardware against your own models. No subscription, no API key, nothing leaving the machine. Persistent memory that actually remembers between sessions.

Pipelines

Tools that do the boring part

Batch processing, asset pipelines, job queues with logs you can read when something fails at 2am. Built to be watched, not to be a spinner.

Apps

Desktop and web front-ends

Interfaces for the above — desktop apps, overlays, local web UIs. Including the awkward ones: transparency, multi-monitor, always-on-top.

Worth knowing before you ask

Local AI needs hardware to run on. Cloe lives on a 12 GB card and that is roughly the floor for a 12B model with anything else running beside it. Smaller models run on less. What I will not do is take your money and then discover your machine cannot host what you asked for — so tell me the GPU early and I will tell you honestly what it can carry.

Pricing

Priced per job rather than per tier, because a simple prop and a multi-part system are not the same work. Tell me the scope and the constraints and you get a number and a turnaround up front. No surprises halfway through, and if a job is out of my depth I will say so rather than find out on your time.
